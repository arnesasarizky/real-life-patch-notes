## The entry

A single-line software patch note for a bug in real life: the knees stop announcing themselves when you stand up after 35 — but the notification does not go away, it relocates to the lower back.

> v2.4.1 — Fixed: knees no longer announce themselves when standing after 35. Side effect: the notification has been relocated to the lower back.

## How to run

Run `node main.ts` from the repository root. The program creates `/output` if needed and writes the line exactly, with no trailing newline, to `/output/entry.txt`.
